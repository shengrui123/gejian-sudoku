# 格間 Sudoku

繁體中文數獨網頁遊戲，採用暖白與森林綠的安靜介面，支援桌面與手機。

- 淺色／深色外觀，預設跟隨系統即時切換，記住手動選擇
- 經典與殺手數獨兩種模式，分別保存最近一題進度
- 簡單、中等、困難三種難度，兩種出題器皆檢查唯一解
- 殺手數獨從空白棋盤開始，提供連通虛線籠框、目標總和、籠內不可重複檢查與總和狀態
- 每日固定挑戰（依裝置本地日期及目前模式）
- 候選數筆記、復原、擦除、每題三次提示
- 鍵盤輸入、方向鍵、N 筆記、Ctrl / ⌘ + Z 復原
- 計時、暫停、完成統計與瀏覽器自動存檔
- 無後端、無執行依賴，靜態檔案可直接部署於 Vercel

## 本機開發

使用 Node.js 18 以上：

```sh
npm run dev
npm test
```

開啟 http://localhost:3000 。在 Vercel 匯入此儲存庫，Framework Preset 選 Other，無需安裝依賴，建置指令為 `npm run build`，輸出目錄為 `dist`。

難度依題目空格數區分；自動存檔為每種模式分別保留最近一題，清除瀏覽器資料會移除進度。Google Fonts 無法載入時會自動使用系統字體。

殺手數獨的單格籠代表該格答案；難度依籠框大小區分。唯一解搜尋超出預算時，出題器會縮小籠框後重新驗證，不會將未完成的搜尋視為唯一解。
